# ROCK-PAPER-SCISSOR-PYTHON
A simple command-line Rock Paper Scissors game implemented in Python. Play against the computer in a best-of-three format!

## Features

- Interactive command-line gameplay
- Best-of-three rounds system
- Score tracking
- Input validation
- Play multiple games

## Requirements

- Python 3.x

## How to Run

1. Make sure you have Python installed on your computer
2. Navigate to the game directory
3. Run the game using Python:
   ```
   python rock_paper_scissors.py
   ```

## How to Play

1. When prompted, enter your choice: 'rock', 'paper', or 'scissors'
2. The computer will randomly choose its move
3. First player to win 2 rounds wins the game
4. After each game, you can choose to play again

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both players choose the same option, it's a tie

## Controls

- Enter 'rock', 'paper', or 'scissors' to make your move
- After a game, enter 'yes' to play again or any other key to quit
